## 🚀 How to Publish Updates to GitHub Pages

### Method 1: Upload Directly on GitHub (Easiest & Fastest)
1. Go to your repository in your browser: [https://github.com/dahliamollen/mollendah](https://github.com/dahliamollen/mollendah)
2. Click **Add file** ➔ **Upload files**.
3. Drag and drop the updated files (`index.html`, `style.css`, `script.js`).
4. Scroll to the bottom and click the green **Commit changes** button.
5. In 1–2 minutes, visit [https://dahliamollen.github.io/mollendah/](https://dahliamollen.github.io/mollendah/) to view your live site!

### Method 2: Using Git in Terminal
If you use the command line on your computer:
```bash
# Navigate to your repository directory
cd /path/to/mollendah

# Check status of changed files
git status

# Stage all files
git add .

# Commit your changes
git commit -m "Update site: Digital Media Education theme with pastel pink, lavender & white"

# Push to GitHub
git push origin main
```
